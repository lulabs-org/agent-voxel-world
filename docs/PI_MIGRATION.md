# Pi Agent 迁移与验收

日期：2026-10-19。基线：`dfe54c034d233296b05fd5fd82fbdc8f34446649`。

## 交付行为

- 服务端和 CLI 统一使用 `AgentRunner`，基于固定版本 `@earendil-works/pi-ai` / `pi-agent-core` 1.3.0。已删除生产环境的 `ModelPlanner`、过渡 `PiPlanner`、旧任务推理循环及后端切换开关。
- 一次唤醒允许多轮推理、顺序工具执行和错误修正。每次请求独立校验、计费；发送前持久化调用计数；禁用隐式重试；失败或取消缺少实际用量时标记估算。
- 保留权限、任务归属、公开与私聊隔离、建造检查点、移动停止、等待唤醒和连续失败检测。当前任务保存最近 8 个完整模型轮次；授权修改任务后恢复该任务历史，无关对话使用临时上下文。
- 检查点保存失败后停止写操作；恢复时将进行中工具标记为未知，聊天和移动不自动重放。旧数据首次加载前保留 `.before-pi.bak`，Agent ID、服务绑定和任务归属不变。
- 一个请求可以产生多个工具批次。历史记录以批次 ID 区分，避免同轮聊天被后续任务控制覆盖。旧记录没有批次 ID 时仍可读取。
- 模型自由文本和推理内容不会进入玩家聊天或 TTS。只有聊天动作产生对外回复。控制台已移除不再生效的 JSON 决策选项。

## 自动化

`pnpm check` 通过：54 个测试文件、519 项测试，包含类型检查和全部工作区构建。Pi 专项直接运行实际核心与 OpenAI SSE 适配器，覆盖超过三次请求、工具参数纠错、预算、失败/取消/超时、同 Agent 互斥、不同 Agent 隔离、消息排队、任务历史恢复、未知动作、检查点失败、连续失败及多工具记录。

管理与任务集成使用真实 Colyseus 和确定性决策夹具验证业务规则；`test:agent:deepseek` 已改为真实 Pi 核心加固定 SSE 响应，验证移动、聊天、编辑、32 块房屋、结果确认与清理。`test:chat` 验证公开/私聊和音频 HTTP 权限。

`REAL_TTS=1 pnpm test:agent:voice`、`REAL_TTS=1 REAL_TTS_MODEL=rhasspy/piper-voices/zh_CN-chaowen-medium pnpm test:voice:services` 验证真实 Piper 音频、托管 Agent 发声、私聊权限、附近播放路由、撤销和保存恢复。固定模型响应与真实模型验收分开计算。

## 真实模型对比

使用同一已配置的 `deepseek-flash`，关闭 thinking；固定初始世界、12 次请求、30,000 token、180 秒任务预算、60 秒请求超时和 1,500 输出 token。每类运行 5 次。世界为固定的内存会话，模型请求是真实请求；这里不模拟网络物理，也不作为生产负载测试。

| 场景     | 旧版成功 | Pi 成功 | 中位请求数：旧 → Pi | 中位 token：旧 → Pi | 中位耗时 ms：旧 → Pi |
| -------- | -------- | ------- | ------------------- | ------------------- | -------------------- |
| 聊天     | 5/5      | 5/5     | 1 → 1               | 3,845 → 3,231       | 1,108 → 912          |
| 移动     | 4/5      | 5/5     | 5 → 2               | 19,788 → 6,957      | 6,316 → 2,369        |
| 建造     | 5/5      | 5/5     | 2 → 2               | 7,998 → 7,032       | 2,373 → 2,222        |
| 纠错     | 4/5      | 5/5     | 4 → 4               | 15,807 → 15,906     | 3,938 → 3,335        |
| 等待     | 5/5      | 5/5     | 1 → 1               | 3,798 → 3,241       | 988 → 913            |
| 中途修改 | 5/5      | 5/5     | 4 → 4               | 16,145 → 14,493     | 3,981 → 3,994        |

最终 Pi 为 30/30，基线为 28/30；每类成功数均不低于旧版，token 和延迟中位数均未增加超过 20%。初次测试中途修改成本超标，已通过合并任务控制与首个动作、返回新观察的编辑确认、避免多余观察请求优化，再全量复测。小样本结果不是对所有任务的成功率保证。

复测脚本：`tests/benchmarks/pi-agent.ts`。原始本机结果位于忽略目录 `artifacts/pi-migration/legacy-benchmark.json` 和 `pi-benchmark.json`；运行方法见 [AGENT_PLAYERS.md](./AGENT_PLAYERS.md#pi-迁移验收与回退)。Ollama 本机 11434 未提供服务，兼容接口未配置独立真实模型：这两类仅通过协议适配测试，真实模型效果未验证。

## Docker、浏览器与恢复

- 实际 `docker compose build server web`、部署和再次重建启动通过。数据库和 speech 容器及其数据卷没有重建或删除，健康接口仍报告 PostgreSQL 持久化。
- 切换前停止 Agent，保留旧镜像、配置/任务副本和 `pg_dump` 世界备份。原 Agent ID、模型与语音绑定保持不变，恢复在线待命，不自动恢复旧任务。
- 浏览器创建独立“Pi 验收”角色，绑定 Chaowen，执行移动、观察确认、聊天与完成任务。最终容器实测 3 次模型请求、28,286 token、约 4 秒完成；同轮动作历史完整保留。实际世界观察比固定基准大，用量不能与上表直接比较。
- 最终镜像另外通过私聊创建新任务：3 次真实请求、29,751 token 完成；任务归属和私聊接收者正确，任务用量等于全局用量增量，首轮意图识别请求没有丢失或重置。
- 私聊使用真实模型，生成真实 Piper 语音；页面实测出现“正在说话 · Pi 验收”并随后结束。测试未采集麦克风，不对声音主观自然度评分。
- 等待任务跨多个心跳不新增请求。容器重启后仍为原任务，状态变为暂停，调用/token 不变，Pi 检查点版本为 1。浏览器手动继续后使用原额度再次进入等待；最后取消验收等待任务。
- 在 `--network none` 的隔离容器中，用旧镜像和备份副本验证回退能启动并读取原 Agent；没有请求模型或修改生产世界。该检查不是将生产世界回滚到旧快照。
- “Pi 验收”已离线，保留历史供查看；原 Agent 继续在线。浏览器收听开关已恢复原设置。
