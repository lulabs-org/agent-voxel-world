## 交付特性与架构革新

服务端与 CLI 运行时已全面统一迁移至基于 Pi 架构的 `AgentRunner` 核心：

1. **多轮链式推理与自动纠错**：单次任务唤醒支持链式连续多轮推理与动态工具调用，工具参数校验失败时支持自主重试修正，告别单轮静态 Prompt。
2. **持久化额度与记账**：模型请求发起前持久化递增调用次数；禁用未经审计的隐式重试；异常中断时标记估算 Token。
3. **任务上下文深度隔离**：当前任务在内存中持久化保留最近 **8 个完整上下文轮次**；修改任务时无缝恢复关联历史，日常闲聊不污染任务历史。
4. **事务级检查点（Checkpoints）**：检查点落盘失败自动中止写操作；服务重启恢复时，执行中的工具动作自动标记为未知状态，聊天与位移绝不盲目重放。
5. **废除旧实现**：彻底移除了 `ModelPlanner`、过渡版 `PiPlanner` 及旧式 JSON 决策逻辑，代码体积与抽象层级大幅精简。

## 真实大模型实测性能对比

测试环境统一采用真实 `deepseek-flash` 模型（关闭 thinking 思考过程），设置 12 次请求上限、30,000 Token 上限、180 秒任务超时与 1,500 输出 Token 预算。每类场景在固定沙箱世界中严格独立运行 5 次取中位数：

| 评估测试场景 |  旧版架构成功率   |    Pi 架构成功率     | 中位请求数 (旧 → Pi) | 中位 Token 消耗 (旧 → Pi)  |   中位耗时 (旧 → Pi)    |
| :----------- | :---------------: | :------------------: | :------------------: | :------------------------: | :---------------------: |
| **基础闲聊** |        5/5        |         5/5          |        1 → 1         |  3,845 → **3,231** (-16%)  |  1,108 ms → **912 ms**  |
| **空间位移** |        4/5        |       **5/5**        |   5 → **2** (-60%)   | 19,788 → **6,957** (-65%)  | 6,316 ms → **2,369 ms** |
| **方块建造** |        5/5        |         5/5          |        2 → 2         |  7,998 → **7,032** (-12%)  | 2,373 ms → **2,222 ms** |
| **参数纠错** |        4/5        |       **5/5**        |        4 → 4         |      15,807 → 15,906       | 3,938 ms → **3,335 ms** |
| **周期等待** |        5/5        |         5/5          |        1 → 1         |  3,798 → **3,241** (-15%)  |   988 ms → **913 ms**   |
| **中途改派** |        5/5        |         5/5          |        4 → 4         | 16,145 → **14,493** (-10%) |   3,981 ms → 3,994 ms   |
| **综合汇总** | **28/30** (93.3%) | **30/30** (**100%**) |     **显著下降**     |   **平均节省 25% Token**   |  **响应时延大幅优化**   |

::: tip 基准压测分析

- **位移决策效率飞跃**：由于 Pi 核心支持连续工具链输出，移动任务的思考轮次从 5 次骤降至 2 次，Token 消耗降低 65%。
- **中途改派优化**：通过在首轮动作中合并意图确认与空间观察返回，消除了旧版本中冗余的多轮观察请求，改派耗时大幅下降。
- **复测脚本**：位于 `tests/benchmarks/pi-agent.ts`。
  :::
